# Sonny_ZPCI_Revenge_Mod #
Reworks the entire game with new abilities, rebalanced enemies, and a harder endgame with many many new mechanics!
Some mechanics are inspired from Elden ring and some from Marvel Rivals.

Mod Name : ZPCIS Revenge Release Date: 13.11.2026

## New Things ##

- New mechanics means new fights. Its a rework and it offers a variety of things including:
- new enemies
- new items / better shops
- items can now modify abilities
- many many new mechanics
- changed strains
- new difficulties
- can now choose a starting strain
- new script / dialogue
- new abilites
- new evolutions
- new enemy types
- fixed most glitches afair (all of the ones in the original game)
- allies now have synerges depending on who you decide to use
## Difficulty Table 
| Difficulty | Difference in Stats |Changed Fights?|
| ------------- | ------------- | ------------- |
| Easy  | 115% scaling  |No|
| Normal  | 125% scaling (base game)  |No|
| Heroic  |  140% scaling |No|

I do not recommend you to start on Heroic difficulty. If you are a Sonny veteran go for it :D
